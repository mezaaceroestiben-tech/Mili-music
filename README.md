# mili music

Cliente alternativo a YouTube Music de código abierto basado en Metro List. 

## Descarga

Descarga el APK más reciente desde la sección **Releases** de este repositorio.

**Versión actual:** 13.9.9

## Instalación

1. Descarga el archivo `.apk`.
2. Ábrelo en tu dispositivo Android y permite instalar apps de origen desconocido si te lo pide.
